# @tanstack/ai-vue-ui (deprecated)

This package is deprecated since 0.3.0. It will be removed in 1.0.0.

Import chat UI from [`@tanstack/ai-vue/ui`](https://tanstack.com/ai/latest/docs/ui/vue) instead.

This package re-exports that subpath so existing installs keep working during the move.

See the [migration guide](https://tanstack.com/ai/latest/docs/migration/create-ui).
