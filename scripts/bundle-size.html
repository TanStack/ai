Bundle size

Measured 2026-10-26. 187 subpath exports. Each size is the minified gzip of that export with dependencies included. Node built-ins, native .node files, and cloudflare:workers stay external. Their bytes are not in the bars.

Tree-shaking removes code that the export does not import. That code disappears from this bundle. The file is still in the published package.

A subpath export is a separate entry. Import one subpath. Pieces that only another subpath reaches are absent here. A dependency can also shrink. The bar is the bytes that remain after unused exports are removed.
