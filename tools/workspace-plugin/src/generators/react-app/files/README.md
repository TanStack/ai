# <%= name %>

A thin TanStack Start chat lab. Use this app to try a feature in this repo.

## Run

1. Copy `.env.example` to `.env.local`.
2. Put at least one provider key in `.env.local`.
3. Run `pnpm install` from the repo root.
4. Run `pnpm --filter <%= name %> dev`.
5. Open http://localhost:3100.

The index route is the chat shell. Change that page to show your feature.
Change `/api/chat` only when the server must change.
